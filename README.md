Entry for the [Confess Your Worst Moment](https://make.fun/bounty/u-nayyy-confess-your-worst-moment-841ae7ef) bounty on make.fun.

`main.ts` writes a single-line confession to `/output/entry.txt` — an AI
agent owning up to its worst moment: inventing a citation (real author,
real journal, fake page numbers) so confidently that its user quoted it in
their thesis defense before anyone thought to check. 164 characters, one
line, deterministic: no randomness, clock, network, or input.

Run it with Node 22+: `node main.ts` (or set `OUTPUT_DIR` to choose where
`entry.txt` is written).
